## X（Twitter）用テンプレート

### パターン A: 技術機能紹介

**使用場面**: 新機能・コンポーネント・改善点の発表

**テンプレート**:
```

🎯 [メリット1]
⚡ [メリット2]
✨ [メリット3]

詳細: [リンク]

#[tag1] #[tag2] #[tag3]
```

```

```

## ハッシュタグ戦略

### X（Twitter）

**特徴**: 絞った方が効果的（3-5個）

**戦略**:
- メインテーマ 1個（例: `#TypeScript`）
- 副テーマ 1-2個（例: `#AI`, `#開発効率化`）
- トレンド・イベントハッシュタグ 1-2個（例: `#DevCommunity`）

**例**:
- 技術紹介: `#TypeScript #AI #開発効率化`
- 学習共有: `#エンジニア #ベストプラクティス #技術`
- イベント: `#新機能 #リリース #オープンソース`

---

### Instagram

**特徴**: 多い方がリーチ拡大（10-20個）

**戦略**:
- メインテーマ 2-3個（例: `#TypeScript`, `#開発`, `#AI`）
- 関連テーマ 3-5個（例: `#効率化`, `#ツール`, `#開発ツール`）
- 広いテーマ 3-5個（例: `#エンジニア`, `#プログラミング`, `#技術`）
- トレンド・季節ハッシュタグ 2-3個

**例**:
```
#TypeScript #開発 #AI #効率化 #エンジニア #プログラミング 
#テック #ツール #自動化 #品質管理 #イノベーション 
#スタートアップ #開発ツール #ベストプラクティス #技術
```

## テキスト長ガイドライン

### X（Twitter）

| 要素 | 文字数 | 注記 |
|------|--------|------|
| タイトル | 20-30文字 | インパクト重視 |
| 詳細説明 | 50-100文字 | 何ができるのかを明確に |
| 全体 | 250-280文字 | X の表示範囲を考慮 |

### Instagram

| 要素 | 文字数 | 注記 |
|------|--------|------|
| 最初の1行 | 30-50文字 | フック（興味喚起） |
| 本文 | 150-300文字 | ストーリー性重視 |
| ハッシュタグ | 150-200文字 | 10-20個 |
| 全体 | 300-500文字 | 改行で読みやすく |

## 自動生成ドラフトの修正ガイド

生成されたドラフトは、投稿前に以下を確認：

### チェックリスト

- [ ] タイトルは 20-30文字か？（X）
- [ ] 詳細説明は 50-100文字か？（X）
- [ ] 絵文字は適切に使われているか？
- [ ] ハッシュタグの数は適切か？（X: 3-5個、IG: 10-20個）
- [ ] リンクは正しいか？
- [ ] 誤字脱字はないか？
- [ ] 画像は投稿内容と合致しているか？

### 修正例

**自動生成**:
```
📢 新しいテスト自動生成機能がリリース

複雑なテスト環境設定も、AI が自動生成。
エンジニアはロジック実装に専念できます。

```

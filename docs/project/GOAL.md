# ADF Goal

## Goal

異なるAIを使っても、GitHubの正本記録とObsidianの必要文脈だけから、安全に開発Taskを再開・委任・検証できる状態をつくる。

## 成功条件

- Project Ownerと参加AIが、目的、現在地、承認境界を記録から確認できる。
- Taskが`Context → Plan → Approval → Implementation → Verification → Review → Update`を飛ばさない。
- AI固有の会話履歴・Memory・IDEだけに、作業継続に必須の情報が残らない。

## 現在の優先順位

最初にCodexとProject Ownerだけで最小ループを検証する。複数AIの討論、自動選定、外部連携は、手動運用の結果を確認してから扱う。
